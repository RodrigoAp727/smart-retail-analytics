# Politica de Seguranca

## Versoes suportadas

Este repositorio usa apenas a branch `main` como versao ativa.

## Como reportar vulnerabilidades

Se voce encontrar uma vulnerabilidade:

1. Nao abra issue publica.
2. Envie um relato privado para o mantenedor do repositorio via GitHub.
3. Inclua passos de reproducao, impacto e sugestao de mitigacao.

## Tempo de resposta alvo

- Triagem inicial: ate 72 horas.
- Plano de correcao: ate 7 dias uteis.
- Publicacao do ajuste: conforme severidade e risco.

## Boas praticas neste projeto

- Nunca versionar segredos reais.
- Usar `.env.example` como referencia de configuracao.
- Revisar dependencias com frequencia.
- Executar lint/testes antes de merge.
