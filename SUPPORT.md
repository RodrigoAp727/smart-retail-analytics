# Suporte

## Como pedir ajuda

Use os canais abaixo:

1. Perguntas de uso: abra uma issue com template de feature/pergunta.
2. Bugs: abra uma issue com template de bug report.
3. Seguranca: siga SECURITY.md e reporte de forma privada.

## Informacoes que aceleram o suporte

- Sistema operacional e versao.
- Versao do Python (`python --version`).
- Comando executado.
- Log de erro completo.
- Passos para reproduzir.

## Escopo de suporte

- Pipeline ETL local e com Docker.
- Estrutura de dados, modelagem e testes.
- Duvidas sobre execucao e contribuicao no projeto.
